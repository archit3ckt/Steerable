# Brand

| File | Use |
|---|---|
| `steerable-mark.svg` | The sailboat alone, as a vector (traced from `steerable-mark.png`). The apps' favicons and the `LogoMark` component (`dashboard/src/logo.tsx`) use it. |
| `steerable-mark.png` | The sailboat alone, 1024px, transparent. |
| `steerable-logo.png` | Sailboat and name, dark text, transparent. For light backgrounds. |
| `steerable-logo-white.png` | Sailboat and name, white text, transparent. For dark backgrounds. |
| `steerable-square-light.png`, `steerable-square-dark.png` | The full logo on a square background, for profile pictures. |

Brand green: `#53ab7e`.
